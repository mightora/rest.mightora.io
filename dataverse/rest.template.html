How does this connect?

1 · Open inside Power Apps

Install as an HTML web resource, then add a Web resource page to your model-driven app navigation.

2 · Use your existing sign-in

The web resource reads the Dataverse context provided by Microsoft. It calls this environment's Web API using your current browser session; no token or password is entered.

3 · Stay in your environment

Only /api/data/v9.2/ requests on the current environment are permitted. Microsoft Graph and other remote APIs require their own authentication and aren't available here.

4 · Understand permissions

401 means your session is unavailable, 403 means access is denied, and 404 may mean the endpoint or table doesn't exist. Changes run under your current user's Dataverse privileges.

Network transparency: Requests are made only when you connect to Dataverse or click a request/discovery action. There is no Mightora relay, analytics, tracking, saved credentials or automatic persistence of records. Press F12 → Network to inspect the activity. A live Dataverse connection is required; this edition is not an offline tool.
