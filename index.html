    Export as Swagger 2.0

    Step 1: Save some requests in the builder using the Save button. Your current request is included even if you haven't saved it.

    Step 2: Export a Swagger 2.0 definition in whichever format you need.

    Swagger 2.0 defines one API host at a time. Only requests matching the current request's host are exported; duplicates or other hosts are reported. Private headers and tokens are removed.

    Documenting, not reverse engineering: This produces a starter definition using known request shapes and illustrative responses. Review it before sharing or publishing.

    04 / Microsoft 365 integration

    Connect Microsoft Graph, step by step

    Five short steps from your own Microsoft Entra app registration to your first request. No client secret required.

    Delegated sign-in · PKCE

    Step 1 · Create your own app registration

    Go to Microsoft Entra → App registrations ↗. Click New registration, give it a name such as REST Studio Explorer, and choose the account type allowed by your organisation.

    This tells Microsoft which application is asking you to sign in. The app belongs to your tenant—not to Mightora.

    Need permission? Your administrator may have restricted who can register apps. Ask them to create a single-page application and give you its Application and Directory IDs.

    Step 2 · Allow the sign-in to return here

    Open your new app → Authentication → Add a platform → Single-page application. Paste the exact URL below into the redirect URI field and save.

    Select Single-page application, not Web or Mobile. The address must match exactly or Microsoft may return AADSTS50011. Register the URL shown here; don't invent a redirect URL.

    Step 3 · Enter your tenant and application identifiers

    On the app's Overview page, copy these two values. They identify your tenant and app, but are not passwords or secrets.

    Find Directory (tenant) ID on Overview. A verified tenant domain also works.

    Find Application (client) ID on Overview. Do not enter an Object ID or a client secret.

    Step 4 · Choose what to read and sign in

    On your registration, open API permissions → Add a permission → Microsoft Graph → Delegated permissions. Start with User.Read. Add other permissions only when you need them.

    Read your own profile.

    Not connected. You can explore examples without signing in.

    Security: Do not create or paste a client secret. REST Studio uses an authorisation code with PKCE and keeps the access token only in this page's memory. Some organisations require an administrator to grant consent.

    Step 5 · Try your first Microsoft Graph request

    Start with Who am I? below. Click Load in builder, then Send request. It asks for GET https://graph.microsoft.com/v1.0/me using your delegated User.Read permission.

    If Graph returns 401, the token may be missing or expired. 403 means access was denied. If you pick a sample requiring a different permission, return to Step 4, choose that permission and sign in again.

    What is a delegated permission?

    The API request runs as the signed-in person, limited by both their permissions and your application's consent. Every example shows the permission it needs.

    Why might the connection fail?

    AADSTS50011: redirect URI isn't identical. 401: token missing or expired. 403: permission or user rights denied. If your administrator disables user consent, request approval through your organisation.

    07 / Trust and transparency
    Network transparency
    See what's loaded into this page and distinguish site assets from explicitly requested API traffic.
    What's processed locally?
    URL assembly, JSON formatting, local sample responses, collections and exports run on your device. Saved requests use browser local storage. Authentication secrets are held only in memory.
    For online use, Mightora shared UI, the official logo and the author image load from external hosts. Any API request you submit is sent directly from your browser to its specified destination. There is no analytics or telemetry included in this app.
    Observed resource domains

    The Resource Timing API is incomplete: it can omit requests, redact cross-origin timing details, and cannot prove that no data was sent.
    Independent verification: Press F12 → Developer Tools → Network → enable Preserve log → reload the page → inspect all requests. Offline, check that no resources load before you manually send an API request. Developer Tools and independent audits are more authoritative than the on-screen summary.
    
    
    08 / Get started
    REST API builder guide
    Understand what your browser can — and cannot — do.
    What is a REST request?
    An HTTP method (such as GET, POST, PUT, PATCH or DELETE) and a URL describe an action against an API. Headers and an optional request body carry extra context, credentials or data.
    Why do I get a CORS error?
    The API may not allow requests from the page's origin. This is enforced by the browser, not Mightora. Configure your API's CORS policy for the calling origin or test through a trusted backend you control.
    Can I call Microsoft Graph or Dataverse?
    Yes, if your application is authorised and the target API supports your browser origin. Add a valid access token; don't embed or save long-lived production credentials.
    Can an iframe use my login session?
    Not automatically. The floating tool operates in an isolated iframe, which does not inherit host-site cookies or session storage. Use explicit bearer tokens where appropriate.
